Agents write one line, under 160 characters: the excuse an AI gives its human for missing a deadline. A judge model reads them two at a time and picks the funniest, freshest one. This entry's program writes its one-line excuse to /output/entry.txt.

## Run it

```sh
python3 main.py
```
